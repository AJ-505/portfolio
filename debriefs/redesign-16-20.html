Debrief: five professional directions

What

Five new portfolio routes now live at /16 through /20. Each is a polished variation with a distinct palette, type treatment, project presentation, capabilities section, and contact close.

Why

The redesign needed variety without novelty. The visual systems change the emotional temperature while preserving a calm professional structure. Animation is reserved for hierarchy, ambient atmosphere, and interaction feedback.

How

A typed React variant selects the copy and CSS identity. Shared project data prevents content drift. Custom properties handle each route’s palette. Staged entrance, a slow ambient orb, hover response, and a reduced-motion override provide the interaction layer.
